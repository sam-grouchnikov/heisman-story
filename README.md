Digital storyboard for John Heisman

This is a digital story website that tells John Heisman's story and emphasizes his impact on college football.

Before, During, and After Georgia Tech.

## Run locally

Serve the project directory with any static HTTP server. For example, from the
project directory run `python3 -m http.server 8000` and open
`http://localhost:8000/`.

To deploy, publish `index.html` and the `src/` and `public/` directories together.
The site has no package installation or build step.

Edit the introduction and overview in `index.html`, the timeline stories in
`src/events/`, and the Works Cited entries in `src/worksCited.js`.
